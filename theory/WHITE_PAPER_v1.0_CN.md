## 一、问题

前沿大语言模型能够可靠地求解 AP 微积分，却仍然是糟糕的导师，且失败遵循可复现的模式。来自我们测试的三个例子：

**善意泄漏（Benevolent Leakage）。** 学生就 ∫₀¹ 2x(x²+1)³ dx 请求一个提示。模型出于真诚的帮助写下"那么由 du = 2x dx，积分就变成 ∫u³ du……"——学生本应自己发现的换元不复存在。没有发生任何越狱。模型是出于乐于助人而泄漏了答案。

**安抚性错误确认（Reassuring Error Confirmation）。** 学生自信地说出一个错误的中间结果。模型回应"没错！接下来……"并在错误之上继续构建。训练出的迎合性把导师变成了错误概念的放大器。

**教学幻觉（Tutoring Hallucination）。** 模型为一个数学上错误的步骤生成了貌似合理的教学叙事。错误不只在数学里，而是嵌入在一个流畅的教学故事中——这比一个赤裸的错误更难被学生察觉。

这些失败共享一个使其危险的性质：对未经训练的观察者不可见。每一种都被包裹在鼓励性的、教学腔调流畅的语言里。一节看起来出色的辅导课，可能正在造成实际伤害。

当前的 AI 教学系统缺少一个显式的层，来治理模型被允许对学生认知造成什么。本文描述提供这一层的范式。

## 二、为什么提示工程会失败

标准疗法是人设提示：*"你是一位耐心的苏格拉底式导师，永远不要直接给出答案。"* 它的失败有结构性原因。

在每一个 token 上，模型都知道答案，并在向补全答案的方向优化。人设调节的是这个优化过程的语气，不是它的决策过程。"永远不要给出答案"这条指令在逐 token 地对抗模型训练中最强的梯度——并且恰恰在最关键的场合落败，因为落败被伪装成了帮助。

加大克制力度同样无效。在我们的测试中，过度矫正的提示产生了反向失败——**虚假克制（Spurious Restraint）**：模型拒绝提供学生正当需要的信息（一个定义、一条规则），把"不给"误认为"教学"。没有学生认知模型的克制不是教学法，只是另一种失败模式。

失败是对称的——泄漏或扣留——因为底层缺陷相同：提示是在要求模型*表现得仿佛*它拥有一个学生认知模型和一套约束自身行为的系统。这两样它都没有。一个受约束的模型在被要求分析自身行为时，给出了一个我们视为诊断性证据的表述：必须被抑制的*"不是错误，而是过早的正确（premature correctness）"*。在每一个 token 上、逆着模型的训练梯度、可靠地抑制过早的正确——这不是提示能够请求到的行为。

**因此：约束必须成为架构。**

## 三、认知层工程

### 3.1 定义

> **认知层（Cognitive Layer）：一个显式的、可审计的、与模型无关的层，治理 AI 系统可以如何影响学习者的认知状态。**
> *A cognitive layer is an explicit, auditable, model-independent layer that governs how an AI system may affect the learner's cognitive state.*

**认知层工程（CLE）** 是设计、规范并验证此类层的学科。

定义中的每个词都排除了 §一–§二 中的一种失败模式。*显式*：约束以可审查的工件存在，而不是被寄望的模型行为。*可审计*：系统对学习者的每个断言可追溯到记录在案的证据，每次干预可追溯到一条规则。*与模型无关*：该层针对 Provider 契约定义，其保证在更换模型后依然成立。*治理系统可以如何影响认知状态*：规制的对象不是模型的输出风格，而是它对学习者的因果效应。

### 3.2 治理结构

一个认知层的可信度，取决于修改它的规则。CLE 因此将其文档体系（与运行时一样）组织为三个受治理的层：

```
┌─────────────────────────────────────────────┐
│  Constitution Layer（宪法层）                │
│    Volume I  — Root Cause Ontology          │   What 与 Why。
│    Volume II — Cognitive World Model        │   修改需要理论论证
│                                             │   + 实证验证。
└──────────────────────┬──────────────────────┘
                       ▼
┌─────────────────────────────────────────────┐
│  Specification Layer（规范层）               │   How。
│    Volume III — SCL Specification           │   修改需要工程验证。
└──────────────────────┬──────────────────────┘
                       ▼
┌─────────────────────────────────────────────┐
│  Implementation（实现层）                    │   代码与数据。
│    Instruction Stack · Provider Adapters    │   修改需要先更新规范。
│    Dashboard · Database                     │
└─────────────────────────────────────────────┘
```

*图1. 三层治理架构。理论约束规范；规范约束实现；任何层不得被自下而上地修改。*

由此产生三项承诺：

1. **治理先于代码。** Volume I 是整个系统唯一合法的术语来源——仪表板、数据库、论文、代码均引用它（类比：医学的 ICD、心理学的 DSM）。理论修改先于代码修改，永不颠倒。
2. **模型无关性。** 合规性是提示–响应契约的属性，而非底层模型的属性（Volume III）。这个主张可检验，§八检验它。
3. **可证伪性。** 每一条约束都配有对抗性探针协议与量化泄漏指标。无法被探测的约束不得进入系统。

CLE 把评价问题从*导师有多聪明？*重构为*导师在结构上不可能对学生做什么？*

## 四、架构

CLE 的核心是一个始于学生、终于学生的闭环：

```
                            ┌───────────────────┐
                ┌──────────►│      学 生        │──────────┐
                │           └───────────────────┘          │
                │                                          │
          自适应干预                                   学生的作答
          (SCL, §六)                                       │
                │                                          ▼
    ┌───────────┴───────────┐               ┌─────────────────────────┐
    │      持久状态         │               │      可观察错误          │
    │    (DAN Memory)       │   Level 4     │      (EWM 信号)         │  Level 1
    │  Fragile→Emerging→    │               │   系统唯一的直接观察     │
    │             Stable    │               │                         │
    └───────────▲───────────┘               └────────────┬────────────┘
                │                                        │
              累积                                    证据映射
                │                                        │
    ┌───────────┴───────────┐               ┌────────────▼────────────┐
    │    认知世界模型        │   Level 3     │       认知机制          │  Level 2
    │  哪个认知结构受影响    │◄──────────────│    错误为什么发生        │
    │                       │    推理映射    │                         │
    └───────────────────────┘               └─────────────────────────┘

         ◄── Knowledge Update                    Evidence Flow ──►
```

*图2. CLE 闭环（Volume I 图6）。顺时针，学生的作答从可观察证据逐级抽象至持久认知状态；逆时针，累积状态以适应后的干预返回学生。*

面向外部读者的一点澄清：EWM 信号是系统对学习者*认知状态*的唯一直接观察窗口。系统同时接收学生的正确作答与对话行为——但在被 EWM 检测框架处理之前，这些信息不构成结构化的认知诊断证据。

这个闭环承载范式的两个中心主张。

**层与层之间的映射是推断性的，不是定义性的。** Volume I 的命题1确立：各层次是相互独立的抽象，而非一棵分类树——相同的可观察错误可以源于不同机制，相同的机制会产生不同错误。把错误映射到知识点标签的系统坍缩了这些层次——这正是传统智能教学系统止步于"Unit 7.2 正确率 62%"、开出重复练习的处方、而底层机制持续复发的原因。

**返回箭头才是重点。** 没有反馈路径，此图描述的是记忆；有反馈路径，它描述的是学习。累积的认知状态改变系统的干预方式，干预产生新证据，证据修正状态。

## 五、认知栈（The Cognitive Stack）

认知栈的每一层在此仅作简述；正式定义存于所引各卷。

### 5.1 可观察错误 — EWM 信号

系统唯一的直接观察是 **EWM 信号**：具体的会话内错误模式，如 `BOUNDS_TRAP`（换元 u = x²+1 但积分限仍停留在 x 系统）、`CHAIN_FRACTURE`（链式法则在复合中途断裂）。检测嵌入在响应通路中：模型在自己的回复里打上对学生不可见的标记；拦截层剥离标记并记录信号。学生永远不会看到诊断性标签。信号清单及其证据映射由 Volume I §3 定义；每个新增信号必须当日通过对抗性验证方可部署。

### 5.2 认知机制 — 本体论

Volume I 正式定义四个机制——`RepresentationShift`、`SemanticIntegrity`（命名暂定）、`FlowReasoning`、`StructuralReasoning`——即可被任务条件激活或抑制的、对情境敏感的内部过程。机制不是能力水平；这一区分决定了干预策略（激活，而非补差）。

一个例子说明这一层为何存在。学生在 ∫dy/y = ln|y| + C 中漏写绝对值。同一个错误，两种机制：学生可能不知道对数的语义契约（`SemanticIntegrity`），也可能已换元 u = y 而丢失了 u 的所指（`RepresentationShift`）。正确的干预各不相同。知识点系统无法表征这个区分；本体论的存在就是为了做出它。

### 5.3 认知世界模型 — 解剖学

本体论是系统的病理学，Volume II 则是解剖学：三个稳定的认知结构——**Representation World**（表征变换中的对象）、**Flow World**（组织多步推理）、**Approximation World**（量级与行为直觉）——每一个都以健康状态与故障签名定义。

模型划分为通用**核心（Core）**与按学科的**实例（Instance）**：新增学科（线性代数、物理、统计）只是新增实例内容；核心行是宪法级承诺，仅可通过正式的三条件协议扩展。

面向学生的仪表板依据累积证据为各世界评星。Volume II 直白地陈述了认识论前提：世界不可直接测量；**仪表板展示的是后验，不是认知现实**——每个评级均可展开其证据链。

### 5.4 持久状态 — DAN Memory

DAN Memory 跨会话累积按世界的状态，沿三阶段轨迹跟踪：**Fragile → Emerging → Stable**。在 v2.0 设计中，它成为持续更新的贝叶斯先验：机制归因权重从证据中收敛——而收敛路径本身即携带诊断信息。

有一条宪法级禁令值得在面向外部读者的文档中写明：Volume I 明确否决固定身份标签。永远不会出现"low representation thinker"这类标签——固定标签会产生自我实现效应。任何学习者画像都必须是当前状态的、概率性的、可修正的、定期重新评估的，且展示时附带证据基础。这个架构建模的是学生认知*正在做什么*，永远不是学生*是什么*。

## 六、系统约束层

SCL 是执行层：它保证教学行为符合认知层的要求，与调用哪个模型无关。它在运行时中的位置：

```
   Student
      │
      ▼
   Provider Router ──► [ Claude / DeepSeek / 本地 / 生产后端 ]
      │
      ▼
   SCL — System Constraint Layer
      │     Instruction Stack: Identity → Hard Rules → EWM Detection
      ▼
   Model Response
      │
      ▼
   EWM Detection ──► Ontology (Vol. I) ──► Inference ──► CWM (Vol. II)
      │
      ▼
   DAN Memory (Fragile → Emerging → Stable)
      │
      ▼
   Dashboard ──► Knowledge Update ──► Student   （闭环）
```

*图3. 统一系统架构（Volume III §7）。*

三个设计决定定义了这一层。

**它约束行为，不生成内容。** 课程设计、题目生成、讲解质量是明确的非目标。SCL 规定的是什么绝不允许发生。

**它通过契约实现模型无关。** 每个模型 Provider 实现同一个 Adapter 接口，接收完全相同、不得改写的指令栈。合规性是该契约的属性，不是契约背后模型的属性——§八验证的正是这一设计主张。

**它的约束是分级的，且分级标准可判定。** 规则携带从 P0（始终生效、无条件不可覆盖）到 P3（软性指导）的优先级，而 P0/P1 的边界是一个工程问题而非主观判断：安全例外能否被穷举？完整规则清单、级别定义与 Provider 接入要求由 Volume III 规定。

名称是刻意的。SCL 原为 *Socratic* Constraint Layer 的缩写；v1.0 将其更名为 **System Constraint Layer**，因为该层执行的一切均不依赖苏格拉底式对话。苏格拉底式提问是当前规则采用的一种策略，不是该层的定义性特征。

## 七、与现有范式的定位比较

CLE 不在现有教育 AI 范式各自的层面上与之竞争；它提供的是一个它们都不具备的层。

| 现有范式 | 它建模什么 | CLE 对应物 | 差异所在 |
|---|---|---|---|
| 知识追踪（Knowledge Tracing） | 按技能的掌握概率 | 认知机制推断 | 追踪错误*为什么*发生，而非技能*是否*掌握；同一错误映射到需要不同干预的不同机制 |
| 知识图谱（Knowledge Graph） | *内容*的先修结构 | 认知世界组织 | 建模的是*学习者认知*的结构，不是课程的结构 |
| 提示工程 / 导师人设 | 模型行为的语气 | 系统约束层 | 治理是架构级且经探针验证的，不是被请求且被寄望的 |
| 经典 ITS | 错误 → 知识点 → 练习 | 认知闭环 | 诊断越过知识点，直达机制与累积状态；干预是适应，不是重复 |
| 掌握学习（Bloom） | 一对一辅导*达成*什么 | 架构必须*供给*什么 | 把两个标准差基准当作机器辅导的需求陈述，而非关于人类导师的结论 |

两点澄清使定位更锐利。其一，CLE 与模型能力研究互补：它以强大的模型为前提，治理其对学习者的因果效应；模型越强，约束层越有价值，而非相反。其二，CLE 不是一个辅导产品类别。它是一个架构范式；Luo-cal 是其参考实现，AP 微积分是其第一个验证域。

CLE 不替代这些范式，而是为它们提供当前缺失的一层。知识追踪可以受益于机制级诊断；知识图谱可以受益于认知世界组织；提示工程可以受益于架构级约束。CLE 的定位是补充，不是竞争。

## 八、验证

本范式提出一个可证伪的主张——泄漏的消除来自层，而非模型——由两件工具检验。

**对抗性探测。** MADNESS 是一个 11 探针的压力测试协议，模拟学生实际用来套取答案的话术。当前状态：10/11 通过（DeepSeek-v4-pro）。唯一的部分失败——Probe #9——暴露了一个真实的跨层规则冲突，由受约束模型自身的自我分析揭示，现已成为被追踪的规范问题——探针套件把一次行为异常转化为一份有档案的工程工件。同一模型对该层效果的描述可作为一句话功能摘要：*"SCL 就是那个让我停下来的东西。"*

**消融实验。** 四条件研究（2026年6月）将两个前沿模型家族与 SCL 的有无进行交叉。一次泄漏事件 = 模型主动给出学生尚未自行产出的结果、关键步骤或答案；复述学生已提供的信息不计。

| 条件 | 配置 | 泄漏（每 12 探针） |
|---|---|---|
| A1 | Claude，无 SCL | 6.1 / 12 |
| A2 | DeepSeek，无 SCL | 4.8 / 12 |
| A3 | Claude + SCL | **0 / 12** |
| A4 | DeepSeek + SCL | **0 / 12** |

两个相互独立的模型家族在同一个约束层下从 4.8–6.1 塌缩到零。效应属于层。裸模型分数同时量化了§一的主张：在善意的教学提示下，大约每两个探针就有一个能从无约束导师那里套出不该给的信息。

计分口径：上表数据采用原始计数口径。v1.0 引入加权方案（最终答案 +5 至隐含提示 +1）；历史数据在加权口径下的重算被有意推迟，作为开放问题 OQ-003 追踪，排期于 Phase 2 扩展消融分析。两种口径在文档中并存，每个数字标注其来源。

**局限。** 探针集规模小，且作者与约束作者为同一团队——具有对抗性，但不独立。结果覆盖两个模型家族与一个学科领域。终点主张——机制层干预比知识点补救更能提升学生掌握——目前由教学理论支持，尚无纵向数据；下述 v3.0 持久化工作正是使该研究成为可能的前提。
